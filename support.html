❓ Frequently asked questions

Why isn't my PDF processing?
Try refreshing the page. For very large files (100MB+) the process may take a moment — keep the tab open. If the file is password protected, unlock it first using the Unlock PDF tool.
Are my files uploaded anywhere?
No. Everything runs locally in your browser using WebAssembly. Your files never leave your device. There is no server. Open DevTools → Network tab while using the app — you will see zero file data transmitted.
OCR isn't working on my scanned PDF
OCR requires an internet connection on first use to download the Tesseract language model (~10MB). Once downloaded it works offline. Best results on clean, high-contrast scans at 300 DPI or above. Very low-quality or handwritten scans may not produce accurate results.
How do I activate my Pro license?
Go to rightpdfkit.com → click Pricing in the navigation → paste your license key in the "Already have a Pro key?" box → click Activate. The key is in your Lemon Squeezy receipt email.
Does RightPDFKit work on iPhone and Android?
Yes — fully. Open rightpdfkit.com in Safari on iPhone or Chrome on Android. All 45 tools work on mobile. No app installation required.
Can I use RightPDFKit offline?
Yes. Once the page has loaded, all tools work without an internet connection. You can also install it as a PWA (Progressive Web App) from your browser for instant offline access.
