Open password vs permissions password

PDF security has two distinct types of password, and they do very different things:

TypeWhat it controlsUse case
Open passwordRequired to view the document at allConfidential files — payslips, contracts, IDs
Permissions passwordAllows viewing but restricts printing, copying or editingShared documents where you want to limit actions, not access

RightPDFKit's Protect tool sets an open password — the strongest form of protection, since the document cannot be opened at all without it.

How strong is the encryption?

RightPDFKit uses AES-256 encryption — the same standard used by banks, governments and enterprise security systems. A correctly chosen password combined with AES-256 makes brute-force attacks impractical within any realistic timeframe.

⚠ The password is everything: Strong encryption only protects you if the password itself is strong. "password123" or your name and birth year defeats the purpose of AES-256 entirely — a weak password is the actual weak point, not the algorithm.

What makes a strong PDF password

  • At least 12 characters — longer passwords are exponentially harder to brute-force
  • Mix of upper, lower, numbers and symbols — avoid simple substitutions like "P@ssw0rd"
  • No personal information — avoid names, birthdays, or anything findable on social media
  • Unique per document — don't reuse the same password across multiple sensitive files
  • Store it in a password manager — not in a text file next to the PDF itself

Frequently asked questions

Can I password protect a PDF that's already password protected?

You'll need to unlock it first with the existing password using RightPDFKit's Unlock PDF tool, then apply a new password using Protect PDF.

Does password protection stop someone from printing the PDF?

An open password prevents the file from being viewed at all without the password. Once opened with the correct password, normal printing and viewing permissions apply unless you also set specific permission restrictions.

Can I password protect a PDF on iPhone or Android?

Yes. Open rightpdfkit.com in Safari on iPhone or Chrome on Android, tap Protect PDF, upload your file, set a password, and download.

Is the password sent anywhere when I set it?

No. The password is used locally in your browser to encrypt the file using AES-256, and is never transmitted, logged or stored anywhere — including by RightPDFKit.

What's the difference between this and Unlock PDF?

Protect PDF adds a password to an unprotected file. Unlock PDF removes a password from a file when you already know the password. They're opposite operations, both free.
