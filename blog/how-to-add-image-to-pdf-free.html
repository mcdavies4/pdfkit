Best practices for image insertion

Choose appropriate resolution

Use images with sufficient resolution for your intended use. For web viewing, 150-300 DPI works well. For print materials, use 300 DPI or higher to ensure crisp, professional results when printed.

Optimize file sizes

Large images can significantly increase PDF file size. Compress images before insertion if file size is a concern, especially for documents that will be emailed or uploaded to web platforms.

Maintain visual consistency

Use consistent image styles, sizes, and positioning throughout your document. This creates a professional appearance and improves readability. Align images with text margins and maintain consistent spacing.

Consider accessibility

When adding decorative images, ensure they don't interfere with text readability. For essential images, consider adding alternative text descriptions for accessibility compliance and screen reader compatibility.
