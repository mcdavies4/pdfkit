💡 Why this list matters: Most "PDF tools" sites only offer 8–10 functions and upload your file to a server to do it. Every one of these 67 tools runs locally in your browser using pdf-lib, PDF.js and Tesseract.js — the AI tools are the only exception, since language understanding requires sending extracted text (not the file itself) to a model.

How these 67 tools are organised

Roughly speaking, the tools split into two types:

  • Offline-first tools (60 of them) — merging, splitting, signing, converting, compressing, securing. These work even if you disconnect from the internet after the page loads.
  • AI-powered tools (7 of them) — summarise, chat, translate, simplify, extract data, proofread and grammar polish. These need a connection to process language, but your file is still never stored.

Frequently asked questions

Are all 67 tools really free?

Yes. Every tool listed here is free, with no account, subscription or credit card required.

Do I need to upload my PDF to use these?

No. Everything processes locally in your browser. The AI tools send extracted text to a model for processing, but the original file itself is never uploaded or stored anywhere.

What's the difference between the standard tools and the AI tools?

Standard tools run entirely offline using browser-based libraries. AI tools like Summarise and Chat need an internet connection because language understanding can't run fully on-device yet — but your file stays private either way.

Which tool should I start with?

If you're new here, Merge, Compress and Sign cover the most common everyday needs. From there, explore based on what you're working on.
