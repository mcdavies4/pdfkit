Why merge PDFs locally instead of uploading?

When you merge PDFs using iLovePDF, Smallpdf or Adobe's online tools, your documents are uploaded to their servers. For payslips, contracts, medical records, passport scans or anything confidential — that is a real privacy concern even if the provider deletes files after processing.

RightPDFKit uses pdf-lib, a WebAssembly library that runs entirely inside your browser tab. The PDF bytes are never transmitted anywhere. You can even turn off your internet connection after the page loads and it will still work.

Getting the order right the first time

The most common mistake when merging PDFs is getting the page order wrong — especially when combining many small files. A few habits that help:

  • Rename files before uploading — prefix them 01-, 02-, 03- so they sort predictably in your file browser before you even drag them in
  • Double-check the thumbnail preview — RightPDFKit shows a preview of each file before merging, so confirm the sequence visually rather than relying on filenames alone
  • Merge in small batches — if combining 10+ files, merge them in groups of 3–4 first, then merge those results together. Easier to verify order at each stage

Merging different types of PDFs together

📄

Digital + scanned pages

You can merge a digitally created PDF (like a Word export) with a scanned document without any conversion. RightPDFKit treats both as standard PDF pages and combines them seamlessly.

📐

Different page sizes

Merging a US Letter page with an A4 page works fine — each page keeps its own original dimensions in the combined file. Most PDF readers handle mixed page sizes without issue.

🔐

Protected + unprotected files

Password-protected PDFs need to be unlocked before merging. Use the Unlock PDF tool first, then combine with your other files.

Troubleshooting common merge problems

⚠ Merge button greyed out? Make sure you've uploaded at least two files — RightPDFKit needs a minimum of two PDFs to merge.
The merged file won't open in some PDF readers

This is rare but can happen if one of the source files was already corrupted. Try opening each source file individually before merging to confirm it isn't damaged.

One of my files shows as blank pages after merging

Check the original file isn't password-protected or uses a restricted permission set that blocks content extraction. Unlock it first, then merge.

Frequently asked questions

Can I merge password-protected PDFs?

You need to unlock them first. Use RightPDFKit's Unlock PDF tool to remove the password from each file, then merge them. Both tools are free and process locally.

Will the merged PDF be too large?

The merged PDF will be roughly the sum of the individual file sizes. If the result is too large, use the Compress PDF tool afterwards to reduce its size — also free in RightPDFKit.

Can I merge PDFs on iPhone or Android?

Yes. RightPDFKit works on mobile browsers — Safari on iPhone and Chrome on Android. Open rightpdfkit.com, tap Merge PDFs, and select your files from Files or Downloads.

Does merging change the PDF quality?

No. Pages are copied directly from the source files without re-rendering or re-compressing. Fonts, images and formatting remain identical to the originals.

Can I undo a merge?

The original files on your device are never modified. RightPDFKit creates a new file when you click Download. Your source PDFs remain exactly as they were.

Why did my merged PDF come out in the wrong order?

Files are merged in the order they appear in the upload list. Drag each file thumbnail to set the order you want before clicking Merge — the result follows exactly what's shown on screen.
